# 03 · 跨学科适配

| 研究类型 | 重点标准 |
|---|---|
| 自然科学、工程 | 原理、实验设计、误差与可复现性 |
| 医学、健康科学 | 伦理、偏倚、适用研究报告规范 |
| 社科定量 | 测量效度、抽样、识别和混杂 |
| 定性、新闻传播 | 取样、编码、研究者反身性与反例 |
| 教育学 | 教学情境、测量、外推边界 |
| 人文历史 | 原始史料、版本、语境、解释立场 |
| 法学 | 规范层级、适用时间、辖区与判例 |
| 叙述性综述 | 分类框架、综合比较、研究分歧 |
| 系统/范围综述 | 实际检索、筛选、纳排和报告规范 |

```text
请根据我的研究材料判定主学科研究类型，并选择相应的论证结构、证据标准、伦理注意事项和质量检查项。对于不适用的实验、统计、样本或 PRISMA 项目，不要硬套。区分已完成研究和计划研究。
```
