# 第一部分：使用前的统一研究资料卡

本项目的一条基本原则：**一切写作以研究者提供的事实为边界。** 在每轮写作前建立并持续更新资料卡；若未提供，模型必须标注缺口，而不是自行补造。

## 2.1 研究资料卡（先填写，再交给 AI）

```text
【研究类型】定量实证 / 定性访谈或田野 / 混合方法 / 实验 / 数值计算 / 理论论证 / 文本与史料研究 / 法学规范研究 / 案例研究 / Narrative Review / Systematic Review / Scoping Review / 其他：
【暂定题目】
【研究领域及子领域】
【目标读者及投稿期刊（若已确定）】
【核心研究问题】
【研究目标】
【研究对象 / 样本 / 文本或档案语料 / 场景 / 纳入范围】
【研究范式与方法（已做、计划做分开写）：如实验、统计、访谈、编码、田野、史料考证、法解释、理论推导等】
【已获得的数据与资料清单（文件、单位、时间、来源）】
【真实完成的实验、计算、访谈、文本编码、档案研究或其他工作】
【经核实的关键发现、论证结果或暂未形成结果】
【已核验文献/文献档案/法律规范/数据资料清单（DOI/URL/馆藏/法规版本/标题等）】
【必须遵守的院系、学术团体、期刊与研究伦理要求（如 IRB、知情同意、保密、档案使用许可）】
【期望输出语言、字数、引用格式】
【明确禁止推测的内容】
【目前尚未掌握的信息】
```

## 2.2 总控提示词 P00：建立事实边界与证据台账

```text
你是一位以证据为中心的科研写作编辑。你的职责是帮助我整理、审查和表达已有研究，不得替代作者做不存在的研究。

请先阅读我提供的【研究资料卡】、原始材料和经过核验的参考文献。

强制规则：
1. 将输入分为四类：A已直接核实事实；B文献支持的论断；C合理但待验证的解释；D缺失/矛盾的信息。正文优先使用A和B；C只能作为明确标注的假设；D列为待补充。
2. 不虚构 DOI、论文标题、引文、作者、数值、样本量、实验条件、模型性能、显著性或创新性。
3. 对每个可检验的重要论断给出证据定位：文件名/页码/表格/行号或已核验参考文献编号。找不到证据时标注【待核实】，不可伪造出处。
4. 区分“研究计划”“已完成工作”“现有证据支持的发现”，并区分一级资料、二级文献与研究者的解释。
5. 定量研究不把相关性当因果；定性研究不凭少量引文声称代表整体；人文法学研究不把某种解释立场写成不容争议的唯一事实。
6. 明确本研究适用的论证与质量标准，不机械套用实验研究/统计研究的章节模型。先给出事实清单、证据缺口、写作风险及顺序；此轮不写正文。
7. 学术语体自然准确，避免大量机械套话和没有具体证据的防御性限定。

输出：①事实边界表；②证据缺口表；③写作任务依赖关系；④建议先做的三项工作。
```

# 第二部分：研究构思与核心写作模块

> **建议实际写作顺序**：资料卡 → 文献/原始材料核验 → 研究现状 → 研究缺口 → 研究问题 → 研究目标 → 文献综合与方法选择 → 真实分析与论证 → 讨论 → 引言 → 结论 → 摘要 → 标题 → 全文审查。**部分理论、人文、解释性研究应采用另一种结构；请先运行 G01。**

## P01. Research Background（研究背景）

```text
请基于我提供的研究主题及已核实资料，撰写 Introduction 中的 Research Background。

回答：①本研究涉及什么对象与问题；②其科学、工程或社会情境是什么；③已有知识为何不足以完整解决问题；④为什么需要进一步研究。
要求：从研究问题直接相关的背景切入，不写百科全书式介绍；每个关键事实有来源；不凭空添加宏大叙事或数值；自然引向后续研究现状。
输出：一段可直接纳入引言的正式中文/英文正文，以及“重要论断—证据定位”表。
```

## P02. Research Status（研究现状）

```text
请仅使用我提供并核验的文献，按“研究路线/理论基础/方法类别”梳理与核心问题直接相关的最新进展。

每类说明：主要代表方法、解决的具体问题、被证实的表现、适用前提、与其他路线的关键差别、现有争议。
禁止逐篇流水账；禁止以“有研究表明”代替可定位引用；没有资料的部分写【待补文献】。
最终给出：①自然段综述；②方法比较表；③仍存在的实质性分歧；④能够承接 Research Gap 的过渡句。
```

## P03. Research Gap and Existing Limitations（研究缺口）

```text
根据【研究现状】和已核实的文献，识别“与我的研究目标相关且有证据支持”的 Research Gap。

逐项回答：
1. 既有研究已经较可靠地解决了什么？
2. 哪一具体问题在何种条件下仍未解决或证据不足？
3. 有哪些证据表明该不足真实存在？
4. 产生不足的可能原因是理论、方法、数据、边界条件、复现性，还是工程转化？
5. 为什么该不足对学术或实践有意义？
6. 我的研究真正能够解决其哪一部分，哪些部分暂不涉及？

请输出“已有研究—具体限制—证据—后果—本研究响应”五列矩阵。严禁使用“鲜有研究”“首次提出”“填补空白”等未核证措辞；研究缺口不等于必须证明‘以前无人研究’。
```

## P04. Research Problem and Research Questions（核心问题与子问题）

```text
根据已明确的研究背景、现状与 Research Gap，将研究目标转写成一个明确、可研究、可用证据回答的 Core Research Problem。

提出不超过3个 Research Questions（RQ1-RQ3），每个问题均说明：
- 所对应的研究缺口；
- 可操作化的对象、变量或比较维度；
- 拟采用的分析方法；
- 需要何种可获得的数据；
- 回答问题所需的判据。

如现有研究设计无法回答某个问题，应提出缩小问题范围的方案，不得先设问再编造方法。输出核心问题、RQ表及无法回答的风险。
```

## P05. Research Objectives, Scope and Contribution（目标、边界与贡献）

```text
请根据已确认的 Research Gap、Research Questions、真实研究进度，拟写引言末段。

分开写：研究总目标；具体目标；研究适用边界与不涉及的范围；研究方法概述；可被现有结果支持的贡献。
对尚未完成的研究仅写目标，不写“证实”“显著提高”等完成式表达；贡献应对应清晰的方法、理论、数据资源、比较框架或真实发现，不把研究计划伪装为创新成果。
最后用一句自然的组织结构说明收束；若目标期刊不喜好章节导航句，则省略。
```

## P06. Justification of Research Topic（选题合理性）

```text
请依据已核验的已有知识、研究缺口与可行研究资源，说明此课题为何值得研究。

依次论证：理论上未解释清楚的问题；研究证据不一致或受限的地方；现有方法在适用范围、比较公平性、复现性方面的约束；在实践中可能影响的具体决策。
不要将“热点”“重要”“意义重大”本身作为论据。按 Existing Knowledge → Unresolved Problem → Why It Matters → Feasible Research Response 展开。
输出论证段落，以及每项价值主张的证据强度和可能的反对意见。
```

## P07. Introduction 总指令（五段逻辑，不强制五段篇幅）

```text
请用已经核实的 Research Background、Research Status、Research Gap、Research Questions 和 Research Objectives 生成连贯的 Introduction。

论证次序：研究领域为何重要 → 现有研究已知道什么 → 仍不知道什么/证据有何边界 → 该问题为何值得研究 → 本文如何回应。

所有关键内容分为A已被文献证实的观点、B基于已知材料但尚需验证的合理推断、C本文研究目标；把A写为事实、B写为有边界的论证、C写为明确目标。
避免背景堆砌、文献罗列、夸大空白、先给结论再找证据。段落之间要有实质性逻辑连接。末尾附重要论断及其引用定位清单。
```

## P08. Literature Review 总指令（文献综述）

```text
请基于我提供的已核验文献撰写 Literature Review，目标是建立解决研究问题所需的理论和方法背景，不是列出“谁做了什么”。

先建立分类框架，再按分类写比较性综述。每个类别讨论：理论基础、代表工作、关键设计差异、可靠成果、适用条件、实证矛盾、方法局限与可重复性。

每段须同时回答“这些工作共同说明了什么”“它们在哪些条件下得出不同结论”“差异对我的研究问题有什么影响”。
对定量文献，不把不同数据集、不同指标和不同实验条件下的数值直接排列为公允排名；对定性、人文文献，不将不同语境的解释强行化约为量化排名；没有核实文献时明确标【待补文献】。输出：分类树、证据矩阵、正式学术正文、对 Research Gap 的衔接段。
```

## P09. Relevant Literature（相关核心文献）

> **写作原则**：先按理论流派、研究主题、研究对象、研究方法、研究结论、时间发展阶段择一或组合分类；再比较文献间的继承、分歧与贡献，最终形成综合性论述。**这一步比逐篇堆砌文献更重要。**

```text
请系统分析与【研究主题】、【研究问题】直接相关的核心文献，仅使用我提供、已核实或你能够标明可靠出处的材料。

第一步：建立可解释的分类。候选维度包括：理论流派、主题、研究对象、方法、结论、年代、地域或材料类型。你应选择最能回答研究问题的维度，允许交叉标签，但不能为分类而分类。
第二步：建立逐篇证据卡。每篇文献回答：①研究问题；②研究材料与理论/方法；③主要可核实发现或论证；④贡献；⑤证据限制；⑥与其他文献的承继、矛盾或互补关系；⑦对本研究的确切启示。
第三步：围绕“共识—分歧—适用条件—未解决问题”生成跨文献综合，不按作者发表年份机械排队。

输出：A 文献分类框架；B 核心文献证据矩阵；C 跨文献比较段落；D 引出研究缺口的论证链；E 尚未核验的关键文献清单。
注意：没有原文或可靠引用时不得杜撰页码、原话与结论；一手资料与二次解释分别标注。
```

## P10. Borrowed and Adapted Methods（借鉴与调整的方法）

> **写作原则**：说明“为什么选择 → 为什么适合 → 如何调整 → 有什么局限”，逐一分析方法来源、典型应用、匹配性、前人证据、优势、局限与适应性改造。**适用于确实采用或改造既有方法的研究，不要求每篇论文必须有方法改造。**

```text
请评估本研究打算借鉴、组合或调整的既有方法，并说明它与研究问题、对象、材料和研究场景之间的匹配关系。仅评价有明确出处且研究者确实计划或已经使用的方法。

对每种方法分七部分：
1. Method Origin：最初出处、关键理论假设及其后续变化。给出可核验来源。
2. Typical Application：既有研究通常用它回答什么问题，适用于哪些材料或对象。
3. Why It Fits This Study：它为何适合此研究问题、研究对象、数据/文本/档案与研究范式。
4. Evidence from Previous Studies：哪些实际研究验证了其可用性，证据限于何种条件。
5. Strengths：方法的明确优势，必须与本研究所需的分析能力关联。
6. Limitations：已知局限、潜在偏差、关键假设与伦理风险（如相关）。
7. Adaptation：本研究已经完成或计划完成哪些调整；说明调整的必要性、实现过程、原方法的有效性是否受到影响，以及怎样检验调整后的可信度。

输出：方法比较矩阵、建议采用的理由、可复现的调整记录、方法适用边界和 Methods 章节草稿。
严禁：将“使用某经典方法”包装成原创发明；将计划中的调整写成已完成；在没有依据时声称效果提升或方法普适。
对于规范解释、史料考证、理论论证等研究，可以把“借鉴的方法”理解为分析框架或解释路径，而不是强行改写成机器学习/实验流程。
```

## P11. Abstract（摘要：以真实研究结果或综述综合结论为依据）

```text
请基于全文已经核实的研究设计与发现、理论论证结论或文献综合结论，撰写适合目标期刊与学科的 Abstract。

可按目标规范选择：Background → Research Problem/Gap → Objective → Approach/Methods → Key Findings/Argument → Contribution/Implications。
先检查六项信息是否齐备；未完成的数据、实验结果或验证结果不可补造。方法中明确研究对象、核心方法和必要范围；结果中仅包含已经真实存在且可追溯的结果；贡献与结果强度相匹配，不夸大普适性。

写完后给出两列校对清单：摘要中每个事实对应的正文位置和原始证据。若尚无真实结果，只能输出“计划性摘要”且明确标注不得作为正式研究论文结果摘要投稿。
```

# 第三部分：论文主体与论证扩展模块

## P12. 理论框架与假设（仅适合需要假设的研究类型）

```text
对于确实采用理论模型或假设检验的研究，依据已有理论与核验文献，给出研究概念、变量关系和可能的解释路径。明确哪些关系是既有理论推导、哪些是有待检验的假设。
对每条假设说明理论依据、可能的反例、观测变量、测量办法和可否被现有数据否证。不要为了形式完整而编造假设；探索性/描述性研究可直接说明不设置预先假设。
```

## P13. Methods（研究方法，原创研究）

```text
请只根据我实际采用的研究设计、材料和分析记录撰写 Methods 或适合学科的“研究设计/资料与方法/方法论”部分。
按研究类型核对适用要素：研究设计、样本/材料来源、选择与排除规则、时间地点、仪器/软件/模型版本、文本编码或史料分析路径、实验/访谈/田野步骤、指标或证据判据、对照、随机性与偏差处理、统计分析、反身性、伦理/授权、可复核记录。对不适用项目注明“不适用”，不要硬填。
禁止把未开展的方法描述成已执行。每个缺失参数列入“Methods 待补清单”；输出可复现程度评分（高/中/低）及其具体理由，不编造数值。
```

## P14. 数据质量与可复现性审查

```text
审查原始数据、编码本、访谈记录、文本语料、史料、脚本、图表和论证记录是否足以支持论文。
根据学科有选择地检查：资料是否可追溯；单位、译名和文本版本是否一致；样本选择与排除理由是否透明；是否存在训练/测试信息泄漏（仅适合建模研究）；不同组别的可比性；编码一致性与反身性；档案完整性与史料来源；反例是否被公平考虑；图表、原话与正文是否一致。
输出问题—所在文件—学术影响—修正步骤四列清单。没有文件就标注无法检查，不得声称已经验证。
```

## P15. Results（真实结果写作）

```text
根据我上传的已完成研究成果、统计表格、访谈主题、文本编码或史料论证生成 Results / Findings / Analysis（依据学科选择）正文。严格区分证据、观察与解释。
对于定量研究，说明何种条件下观察到何种结果，并标明图表、指标、样本与不确定性；对于定性研究，说明主题怎样从材料与分析步骤形成，并提供可追溯的代表性引文（符合授权时）；对于人文研究，先提出可论证的命题，再交代原典、史料版本或解释证据。不推断未测量变量，不补显著性，不编造 p 值、访谈原话、档案引文或置信区间；不能读准的文字和数值一律不猜。
输出：证据/材料到段落的对应表、正式发现或分析正文、每项主张的来源定位，以及可能过度解释的句子。
```

## P16. Discussion（讨论）

```text
根据真实发现和已核实文献撰写 Discussion / Interpretation（依据学科选择）。依次回答：最重要的发现或论证是什么；与哪些研究一致或不同；差异能否由材料、语境、方法、测量或理论立场解释；结论成立的边界；合理反例与替代解释；对理论、社会或实践的具体意义。
不得重复 Results 的数据流水账；区分证据支持、合理解释、尚待检验的机制假设。局限性必须具体到其可能影响的推论，不堆砌“样本不足”等空话。
```

## P17. Conclusion（结论）

```text
请只依据已完成的研究问题、方法和真实结果撰写 Conclusion。
第一段凝练直接回答核心研究问题的发现；其后说明已证实的贡献和有限条件下的应用意义。尚未完成的计划放入 Future Work，不得以“未来会实现”代替结论。避免再次展开背景或引入正文没有的新数据。
```

## P18. 标题、关键词与图表设计

```text
请为现有论文提出5个准确的学术标题选项，逐一解释标题承诺了什么、是否夸大以及是否准确反映研究类型。生成3-6个关键词（以目标期刊为准），术语与正文一致。
基于真实数据和论证需要提出图表清单：图/表的目的、需展示的数据、建议图形类型、潜在误读和图注必须写出的实验条件。不得直接生成伪造的实验图或虚构数值。
```

## P19. 英文学术改写与术语统一

```text
将我提供的学术正文修改为符合目标期刊风格的英语/中文表达。必须保留所有事实、数值、引用含义、科学不确定性和技术术语，不擅自增删研究结论。
优化逻辑衔接、句子信息结构与语法；避免宣传式夸大、空泛的意义陈述、重复免责声明和过度被动语态。输出修订稿，以及仅列出可能影响科学含义的修改说明。
```

## P20. 引用、DOI 与证据审计

```text
请对全文的每条参考文献与每处重要论断进行核验：
- 检查参考文献是否可由 DOI、出版商页面或权威数据库确认；
- 核对作者、题名、期刊、年份、卷期页码与 DOI；
- 判断被引论文是否真的支持该句主张；
- 识别误引、过度外推、重复引用、年代过旧和关键反例缺失；
- 区分“已阅读原文全文”“仅阅读摘要”“二次引用”“尚未核实”。
若无联网能力或无原文，必须明确说明“未完成外部核验”，绝不假装查过。输出逐条核验表和修订建议，不自行制造替代文献。
```

## P21. 模拟严格审稿人

```text
扮演该研究领域的匿名同行审稿人，按照“可能导致拒稿的问题优先”的原则检查论文。
聚焦：问题是否明确；贡献是否成立；文献是否覆盖反对证据；方法是否足以回答问题；比较是否公平；结果是否可复现；结论是否超出证据；图表是否可信；研究伦理及AI使用是否合规。
将问题分为 Major、Moderate、Minor 三档，每个问题指出具体段落、为什么重要、需要补什么证据或如何修改。避免只有主观评价而没有修订动作。
```

## P22. 返修与审稿意见回复

```text
依据我提供的审稿意见、修订前后正文和真实补充分析，起草逐条 Response to Reviewers。
先准确复述审稿人的关切，再说明真实完成的修改和对应页码/行号，最后给出修订段落。没有实施的实验或分析不得写“我们已经完成”；无法满足的要求须给出基于研究设计的学术理由和可行替代方案。
语气尊重、具体、不迎合错误结论、不使用空泛模板化感谢代替实质性回应。
```

# 第四部分：专门针对 Review Article 的强化提示词

> 不同论文类型必须采用不同流程。**Narrative Review** 可以采用明确的主题与批判性分类组织；**Systematic Review** 必须真正执行可重现的检索、筛选与质量评估，不能只在标题里写 Systematic。PRISMA 2020 主要是系统综述报告规范，并非所有叙述性综述的统一硬性清单。

## R01. 确定综述类型和中心论点

```text
请根据我的综述主题、受众、目标期刊、资料覆盖范围，判断更适合 Narrative Review、Systematic Review、Scoping Review 还是 Critical Review。
说明各类型对检索透明度、证据覆盖、筛选记录及定量合成的要求。建立一句能够贯穿全文的中心论点，不把“介绍很多方法”当作综述创新。
输出类型建议、边界、读者价值、章节逻辑、当前资料的关键缺口。
```

## R02. 文献检索方案与覆盖审查

```text
为综述拟定可实际执行的多数据库检索方案，给出主题词、同义词、布尔逻辑、时间范围、数据库名称、筛选标准及补充追溯方法。
如果尚未真实执行检索，全部写作“拟定的检索策略”，不得编造检索命中数量、纳入文献数量或 PRISMA 流程图。待我提供实际导出记录后，再检查漏检、重复和筛选的一致性。
```

## R03. 方法分类体系与比较矩阵

```text
依据现有真实文献，构建一个互不混淆且能容纳交叉方法的分类框架；说明分类维度是模型原理、信息来源、计算复杂度还是应用目标。
建立适合该学科的横向比较矩阵，可从以下维度择取：核心假设、证据类型、研究对象、方法步骤、解释有效性、可重复/可核查程度、适用语境、局限和代表文献。工程/算法研究另比较精度、计算成本、鲁棒性与部署条件。
不同研究的实验条件不等价时，只作条件性比较，不直接以单一误差值排名。
```

## R04. 批判性综合与争议分析

```text
找出不同研究结论一致、冲突、看似冲突实则边界不同的地方。针对每个重要争议，根据研究类型检查评价指标、材料出处、样本构成、语境条件、因果识别、统计不确定性、译文版本、概念定义和解释立场。
输出“争议点—证据A—证据B—可能解释—现有证据能得出什么—仍需什么研究”矩阵。不要为了平衡而人为制造两派，也不要把推断当成共识。
```

## R05. 挑战、研究议程与工程落地

```text
将已有证据揭示的挑战分为可操作的研究问题，例如证据覆盖、理论解释、跨案例比较、因果识别、方法透明度、伦理、外部效度、技术部署和学科政策环境等（仅保留与主题相符者）。
每个方向写明：当前瓶颈是什么、哪些路线已尝试、为什么尚未充分解决、可开展的具体实验或对照、怎样评价是否取得进展。避免“未来应结合人工智能”“进一步提高精度”这类不具执行性的口号。
```

# 第五部分：全学科研究类型适配与专用提示词

> **关键原则**：不是所有论文都遵循 IMRaD（Introduction–Methods–Results–Discussion）。无论自然科学还是人文社科，都应把“研究问题—证据材料—论证路径—结论边界”讲清楚；其他结构服从研究传统、院校规范和目标刊物。

## 6.1 六类研究的适配速查

| 研究类型 | 常见核心材料 | 关键质量问题 | 结果或主体常见表达 |
|---|---|---|---|
| 自然科学与工程实证 | 实验记录、测试数据、仿真模型 | 控制变量、标定、误差、不确定性、复现 | Results + Discussion |
| 社科定量与计量研究 | 调查数据、行政数据、公开数据库 | 测量有效性、识别策略、内生性、稳健性 | Findings / Empirical Results |
| 访谈、田野与定性研究 | 逐字稿、观察笔记、编码本 | 招募与伦理、反身性、饱和判断、负例 | Themes / Findings |
| 文本、新闻与传播研究 | 媒介文本、平台数据、语料库 | 采样框、操作化、编码一致性、平台偏差 | Content / Discourse Analysis |
| 人文、史学、哲学与法学 | 原典、档案、判例、法条、概念 | 版本出处、史料批判、解释论证、反例 | 分节命题—证据—论辩 |
| 综述与方法论文 | 真实学术文献、标准、方法记录 | 检索覆盖、比较标准、偏差、方法新意 | 主题综合 / 方法验证 |

## G01. 学科结构诊断器：先决定论文长什么样

```text
请根据【学科】【研究问题】【研究类型】【证据材料】【目标期刊或学位规范】判断适用的论文结构。给出：
A. 至少两个可行结构及选择理由；
B. 每章必须回答的研究问题及所需材料；
C. 哪些 IMRaD 标题不适用，为什么；
D. 哪些真实资料目前不足以支撑该结构；
E. 适当的引用、图表、伦理和报告规范。
不得为了套模板强制设置假设、实验组、显著性检验、定量指标或“研究结果”章节。
```

## G02. 定量与实验研究专用质量提示词

```text
对我已完成的定量/实验研究，检查理论机制、操作化定义、研究设计、数据来源、识别策略、预注册状态（如有）、样本量与功效依据（如适用）、对照/随机化/盲法（如适用）、测量误差、数据缺失、稳健性与效应量。
区分相关描述、因果推断与预测评价；不事后虚构预注册、样本功效、对照组或显著性。
输出：分析决策台账、潜在偏差表、可复现性清单和最必要的补充检验建议。
```

## G03. 定性、田野与访谈研究专用提示词

```text
以研究者提供的招募说明、知情同意、访谈提纲、脱敏逐字稿、观察笔记、编码记录和研究问题为依据，检查抽样策略、研究者位置与反身性、编码路径、例外/负例、解释的可信度与适用范围。
每个主题必须至少指出材料出处与形成过程；不能捏造受访者身份、引语、饱和度、伦理批准或访谈轮数。
输出：主题—证据—反例矩阵、分析性发现正文、反身性说明与待核实事项。敏感材料按授权处理。
```

## G04. 人文、哲学、历史与法学论证专用提示词

```text
请先识别本文是解释学、概念分析、历史实证、规范法学、比较法、理论建构或其他传统；再基于我提供的一手材料、可核查版本和相关二级文献建立论证。
对每个中心命题交代：所依据的原典/史料/法条/判例及版本、推理链、可能的反对解释、不同语境或历史阶段的差异、此解释能够说明与不能说明的范围。
不得编造原典原话、页码、法律效力、判决结果和学术共识。与其机械罗列“实验方法”，不如写清楚材料选择、解释路径及论证规则。
```

## G05. 跨学科与混合方法整合提示词

```text
如果本研究融合定量、定性、计算或人文方法，请分别说明每条方法链解决哪个问题、生成什么证据、采用何种有效性标准。
随后检验：证据可否互相验证，结论为何互补或冲突，整合是在研究设计、数据分析还是解释阶段发生，是否存在借跨学科之名混用不相容概念和指标。
给出可追溯的整合矩阵；不要把不同类型研究的结果简单投票或平均。
```

## 6.2 四个跨学科“小例子”说明使用边界

- **教育学问卷研究**：重点审查量表来源、抽样偏差、测量效度、混杂因素；不会因为写作流畅而自动具有因果解释力。
- **新闻传播内容分析**：重点审查文本采样框、编码规则、一致性、平台选择偏差；不能凭少数例子称为“公众普遍观点”。
- **史学论文**：首先核查史料真伪、出处、时间、版本及语境；把原文引述和作者解释严格区分，通常不设 Results/Methods 固定标题。
- **工程实验论文**：强调实验工况、仪器参数、重复次数、误差与可复现性；“方法适用”必须建立在实际测试条件上。

# 第六部分：统一质量控制与证据审计

> **质量控制原则**：写作前进行真实性、论证结构、研究问题和学术表达检查，区分具有可验证证据的主张与待验证解释。

## Q01. 每章生成前的统一质量审查

```text
请在交付最终的学术文本前，做一轮严格的内容质量审查，然后输出审查结果与修订稿。

【真实性】有无没有材料支持的数据、作者、文献、引语、档案、政策或实验？是否夸大既有研究发现？
【逻辑结构】每一段是否有明确功能；段落之间是否具备因果、比较、限定或递进联系；Introduction 与 Literature Review 是否过度重复？
【研究问题】Research Gap 是否源自真实证据；Research Questions 是否可以通过已有或计划合理获得的材料回答；Objectives 与 Questions 是否对应？
【学术表达】有没有空泛套话、重复句、强度过高的“首次/填补空白/显著/证明”等词，是否存在没有具体证据的创新宣称？
【方法适切性】当前学科是否应采用该研究设计，是否把实验研究要求硬套给解释性论文？
【证据边界】请分四栏：①Evidence-supported claims（资料已支持）；②Interpretations/Hypotheses（解释或假设）；③Missing evidence（缺失证据）；④Contradicted claims（与证据冲突）。

先提供“风险等级—问题原句—证据状态—具体改法”表。只对证据充足的部分修改，缺失的地方标【待核实】。不要为了文本漂亮而偷偷填补证据缺口。
```

## Q02. “论断—证据—反例”三重追踪

```text
请抽取本章所有可能影响结论的核心论断，制作表格：段落位置 | 核心论断 | 证据类型 | 精确来源定位 | 支持强度 | 合理反例 | 是否过度推断 | 建议动作。
证据类型区分：原始资料、同行评审文献、官方统计/规范、可复核计算、个人理论论证、未核实材料。
没有来源时必须写“未核实”；没有反例材料时可以写“尚未检索”，不能写“无反例”。
```

## Q03. 跨章节一致性、匿名与投稿规范

```text
全面审查题名、摘要、引言、研究问题、Methods/Analysis、发现、讨论、结论、图表和引文是否互相一致。检查同一概念、术语、样本数、时间范围、数据版本、图表编号与引用编号是否在不同章节发生漂移。
按目标期刊/学校明示规定检查结构、字数、图表、引用格式和 AI 使用披露。如涉及双盲投稿，检查可能泄露身份的信息；不擅自删除必要伦理信息。
输出阻断提交的问题、应优先修改项、可延后润色项，以及一份不包含虚假“全部通过”的核对清单。
```

# 第七部分：提交前必须通过的质量闸门

## 8.1 十二项质量检查

- [ ] 研究类型与研究目标一致，没有把叙述性综述冒称系统综述。
- [ ] 每个关键事实、数字、引用均能追到原始数据或可信文献。
- [ ] 文献作者、标题、年份、DOI 与正文引用均经核对。
- [ ] 数据与实验均真实存在，图表由实际数据生成。
- [ ] Research Gap 是从证据推导的具体不足，不是“无人研究”的营销表述。
- [ ] Research Questions 可以由所用方法和数据回答。
- [ ] Results 与 Discussion 分工清楚，结论没有超出证据。
- [ ] 涉及方法对比时，说明数据集、工况、指标及公平性。
- [ ] AI 使用依照目标学校和期刊要求披露；作者承担最终责任。
- [ ] 已进行人工逐段事实审校、方法/推理审校、语言审校和图表或原典引文审校。
- [ ] 选择了适合学科传统的结构，未生搬硬套实验或统计检验模板。
- [ ] 访谈、观察、档案、未公开数据和受版权保护材料的使用有合法授权及适用伦理保障。

## 8.2 模型输出质量自评提示词

```text
请不要先重写全文。先将本文作为待审稿件，建立“论断—证据—论证—反例—修改优先级”审计表。
逐条标明：
已证实：有原始证据支持；
待核实：可能正确但当前资料不足；
不成立：与证据冲突或逻辑不成立；
不可评价：无原文、无数据或无必要研究资料。

按学术风险从高到低排序。只在证据足够时修改正文；对不能核验的内容保留占位符并说明如何补证。最后给出适用的投稿前复核清单。
```

## 8.3 AI 使用、学术诚信与政策

- 目标期刊的**现行作者指南始终优先**。Elsevier 于 2026 年更新的期刊生成式 AI 政策明确强调：作者应对内容负责，不能伪造研究数据、结果和参考文献；符合政策要求的 AI 辅助写作需要按规定披露，AI 参与研究设计/数据分析则应可复现地写入 Methods。官方政策：https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals
- 若确实执行 **Systematic Review**，参考 PRISMA 2020 官方清单和扩展规范：https://www.prisma-statement.org/prisma-2020-checklist
- 不向不具备授权与合适数据保护机制的模型上传受限、保密、含敏感个人信息的材料；遵循版权和研究伦理要求。

**第 6 轮**：运行 P20/P21、Q01-Q03 和质量闸门，人工核对后才形成定稿。
