# 安装与使用 | Installation

## 对话模式

在 ChatGPT、Claude 等支持读取文本的对话工具中，打开 [启动模板](../prompts/00-start.md)，填写研究资料卡，随后按需要使用 [文献综合](../prompts/01-literature.md)、[分章写作](../prompts/02-writing.md)、[学科适配](../prompts/03-discipline.md) 和 [质量审计](../prompts/04-quality-audit.md)。

## Agent Skill 模式

将本仓库克隆到所使用 Agent 支持的 Skills 文件夹，确保根目录中的 SKILL.md 可以被读取，且 prompts/、docs/ 等子目录保持相对路径不变。各平台的发现规则可能变化，请以其当前官方文档为准。

git clone https://github.com/3150214587/qingyuan-academic-skill.git

## 注意事项

如未提供真实数据或文献，可以协助规划，但不得虚构研究发现。上传含隐私或未授权公开的研究资料前，应核实伦理和保密要求。
